# Yad2 Car Exporter - תוסף כרום ליצוא מודעות רכב מיד2 ל-Excel

תוסף כרום מודרני, מהיר ועוצמתי לחילוץ וייצוא תוצאות חיפוש רכב משומש מאתר **יד2** (`yad2.co.il`) לקובצי **Excel (`.xlsx`)** ו-**CSV**. 

התוסף פועל ישירות בתוך הדפדפן (Client-Side), עוקף לחלוטין מנגנוני הגנה נגד בוטים (כגון Radware Bot Manager), ומאפשר איסוף נתונים מדויק, מהיר ונוח.

---

## 🌟 תכונות עיקריות

* **פנל צף אינטראקטיבי:** מופיע בפינה התחתונה של עמוד חיפוש הרכבים ביד2.
* **ייצוא עמוד נוכחי בלחיצה:** חילוץ מיידי של כל המודעות בעמוד הנצפה והורדת קובץ Excel מפותח וקובץ CSV.
* **סריקה אוטומטית של מספר עמודים:** מעבר אוטומטי בין עמודים, גלילה חלקה, סינון כפילויות ואיסוף רציף.
* **חילוץ נתונים מדויק ואיכותי:**
  * יצרן, דגם, תת-דגם/רמת גימור
  * מחיר אמיתי (מנקה תגיות מבצע כגון *"ירד ב-X ₪"*)
  * שנה, יד, קילומטראז'
  * נפח מנוע וסוג מנוע/תיבת הילוכים
  * קישור ישיר למודעה (`https://www.yad2.co.il/item/...`)
* **הגדרות סריקה מותאמות אישית:** אפשרות להגדרת מקסימום עמודים או מקסימום מודעות לסריקה דרך פנל ההגדרות (Popup) של התוסף.
* **סינון תכנים לא רלוונטיים:** התעלמות אוטומטית מרכבים ממומנים ומסיליידרים של *"דגמים דומים"*.

## 🛠️ הוראות התקנה בדפדפן Chrome

ההתקנה מתבצעת כתוסף פיתוח (Unpacked Extension) במספר צעדים פשוטים:

1. **פתחו את דפדפן Google Chrome**.
2. היכנסו לעמוד ניהול התוספים על ידי הקלדת הכתובת הבאה בשורת הכתובות:
   ```text
   chrome://extensions/
   ```
3. בפינה העליונה (מימין או משמאל, בהתאם לשפת הדפדפן), הפעילו את המתג **"מצב מפתח"** (**Developer mode**).
4. לחצו על הכפתור **"טען רכיב שהורחב"** (**Load unpacked**).
5. בחלון שנפתח, בחרו את התיקייה **`extension`** מתוך תיקיית הפרויקט.
6. התוסף **Yad2 Car Listings Exporter** יופיע ברשימת התוספים הפעילים!

## 🚀 איך משתמשים?

1. היכנסו לאתר **יד2** לעמוד חיפוש רכב משומש: [https://www.yad2.co.il/vehicles/cars](https://www.yad2.co.il/vehicles/cars).
2. בצעו חיפוש או סינון לפי הדרישות שלכם (למשל: יצרן, מחיר, שנה).
3. בתחתית המסך מצד שמאל יופיע **פנל צף ירוק**:
   * **`📊 ייצא עמוד נוכחי`**: מייצא מיד את המודעות שבעמוד הנוכחי לקובץ Excel ו-CSV.
   * **`🚀 סרוק עמודים וייצא ל-Excel`**: מתחיל סריקה אוטומטית שעוברת עמוד-עמוד, אוספת את המודעות ומורידה קובץ Excel מרוכז בסיום.
   * **`⏹️ עצור סריקה`**: מפסיק את הסריקה באמצע ומייצא את מה שנאסף עד כה.
4. **שינוי הגדרות סריקה:**
   * לחצו על אייקון התוסף בסרגל התוספים של Chrome (למעלה מימין).
   * הגדירו כמות עמודים מקסימלית או כמות מודעות מקסימלית.
   * לחצו על **"שמור הגדרות"**.

## 📊 פורמט הקובץ המיוצא

הקובץ המיוצא מגיע בפורמט **Excel (`.xlsx`)** ופורמט **CSV (UTF-8 with BOM)** התומך בעברית בצורה מושלמת ב-Excel.

העמודות בקובץ:
1. **יצרן ודגם** (`Title`)
2. **תת-דגם / רמת גימור** (`SubTitle`)
3. **מחיר (₪)** (`Price`)
4. **שנה** (`Year`)
5. **יד** (`Hand`)
6. **קילומטראז'** (`Km`)
7. **מנוע ותיבה** (`Engine`)
8. **קישור למודעה** (`Link`)
9. **תאריך סריקה** (`ScrapedAt`)
